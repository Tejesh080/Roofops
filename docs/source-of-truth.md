# Source-of-truth contract

Generated by `npm run contract:export` from the `field_contract` table, which **drives** Airtable change capture (`wf_airtable_change`) and
reconciliation (`wf_reconcile_airtable`). Editing this file changes nothing; change the migration.

**Rule:** Postgres is canonical for every business fact. Airtable is an editing surface for the fields marked *editable*; everything else in
Airtable is a projection RoofOps writes and repairs. Google Drive and Xero hold the objects; Postgres holds the verified link to them.

| Owner code | Meaning |
|---|---|
| `POSTGRES` | RoofOps (Postgres) |
| `AIRTABLE_EDIT` | RoofOps (Postgres); staff may change it in Airtable via the validated handler |
| `INPUT` | Airtable input read with another change (not stored as its own truth) |
| `ACTION` | Airtable action button (command, not state) |
| `WORKFLOW` | Written by a RoofOps workflow (projection) |
| `DRIVE` | Google Drive object, verified link in Postgres |
| `XERO` | Xero object, verified link in Postgres |

| Reconcile code | What reconciliation does on drift |
|---|---|
| `APPLY_VIA_HANDLER` | missed edit replayed through the same validation |
| `REPAIR_AIRTABLE` | Airtable put back to RoofOps value |
| `PROJECTION` | Airtable projection refreshed when canonical state is stable |
| `VERIFY_EXTERNAL` | external object read back (Drive / Xero) |
| `IGNORE` | not compared |
